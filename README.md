# Basic React NodeMailer

A simple setup to send basic emails from an input with React, Node.js and Resend. As it's for learning purpose, the 3 projects are in the same repository to keep things tidy.

## 📂 next

Using Next.js included API system for the simplest implementation, without any custom Node.js server.

- Install packages with `bun i`
- Run `bun dev`
- The server will now run on `localhost:3000`

## 📂 react

Using React in its native form, with React Router and the server in the `node/` folder.

- Install packages with `bun i`
- Run `bun dev`
- The server will now run on `localhost:5173`

## 📂 node

Used for in the `react/` folder to setup a Node.js server with the Express framework.

- Install packages with `bun i`
- Run `bun server.js`
- The server will now run on `localhost:5001`
